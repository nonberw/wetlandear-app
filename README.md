# WetlandEar App

Веб-приложение (PWA) проекта WetlandEar: «пульс заповедника». https://app.wetlandear.tech

## Что умеет
- Запись с микрофона или загрузка аудио (телефон работает как виртуальная станция).
- Спектрограмма и поиск звуковых событий.
- Подсказки вида: BirdNET V2.4 с фильтром по месту (после входа через Google).
- Тип звука и тревоги: YAMNet (ветер, дождь, речь, техника, возможный выстрел).
- Подтверждение человеком, уровни доверия: событие, модель предполагает, подтверждено человеком, эталон.
- Пульс, звуковой календарь, карта станций, утренний отчёт (копирование, Telegram, PDF).
- Аккаунт Google, профиль, синхронизация журнала (Supabase), выгрузки CSV и Darwin Core.

## Устройство
Без сборки: `index.html`, `css/`, `js/` (`dsp.js` звук, `store.js` данные, `sync.js` аккаунт и облако, `app.js` интерфейс, `extras.js` карта и отчёт), `sw.js` офлайн.
Сервер: `api/identify.py` (Vercel Python), модели в `models/` (см. `models/NOTICE.md`, лицензии моделей).
База: `supabase/schema.sql`, защита строк (RLS) по пользователю.
