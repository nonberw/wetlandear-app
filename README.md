# WetlandEar App

Веб-приложение (PWA) проекта WetlandEar: «пульс заповедника». Версия 0.1, прототип.

Сайт проекта: https://wetlandear.tech. Приложение должно работать на поддомене `app.wetlandear.tech`.

## Что умеет сейчас
- Запись с микрофона или загрузка аудио (телефон выступает «виртуальной станцией»).
- Спектрограмма и поиск звуковых событий (вид птицы не определяется автоматически).
- Подтверждение человеком: вид, «Верно», «Ошибка». Очередь проверки.
- Пульс заповедника, звуковой календарь, первые обнаружения сезона.
- Выгрузка: журнал CSV, Darwin Core CSV (только подтверждённые), резервная копия JSON.
- Все данные остаются на устройстве (localStorage + IndexedDB).

## Что дальше
Автоматическое определение вида (открытая модель как baseline), карта станций, подключение ESP32-S3, утренний отчёт.

## Структура
Без сборки: `index.html`, `css/app.css`, `js/dsp.js` (звук), `js/store.js` (данные), `js/app.js` (интерфейс), `sw.js` (офлайн).
Публикация: Vercel, автодеплой из ветки `main`. Заголовки безопасности и строгая CSP в `vercel.json`.
